# examples

Reference implementations for harmoni and kit.

Each example demonstrates a complete service built with harmoni + kit across different transports.

> Inspired by [go-kit/kit](https://github.com/go-kit/kit)

## Examples
- `addsvc` — The canonical "add" service (HTTP, gRPC, NATS, AMQP)
- `profilesvc` — A more complex service with all middleware layers
